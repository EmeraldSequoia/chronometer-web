# Planning Archive

This directory contains dated planning documents from the development of
Chronometer Web (March 2026 onward — the initial Chronometer port, then
Observatory, the Inspector, the localStorage state migration, and the
performance work). They record the design decisions, implementation
strategies, and debugging notes from each effort.

**For current implementation reference, see [`docs/`](../docs/).**

The docs directory contains permanent, subsystem-focused documentation
distilled from these planning files and kept up to date as the codebase
evolves.
