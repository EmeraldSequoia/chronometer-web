Found a bug? Please report it on the GitHub issues page. Describe what you saw and what you expected, and mention which app and which browser and device you were using, along with the app’s version number (shown at the bottom of the help popup opened by the ℹ︎ button, e.g. “v2.1.8”).

This free web app is maintained by volunteers, so no support or response time is promised — but the developers do read the reports and fix most bugs.

The website itself only serves, as a convenience, files available from the GitHub releases page (see instructions for running the app here).
